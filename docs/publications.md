# Публикации ARAVA

Раздел «Публикации» предназначен для новостей, объявлений, афиши и информационных сообщений в личном кабинете. Владелец может публиковать для всех клиентов, выбранных филиалов, групп или тренеров. Администратор с ограничением по филиалам видит и выбирает только разрешённые филиалы и группы; тренеру управление недоступно.

Черновик хранится только в локальной базе CRM. При публикации запись и операция существующего `SyncOutbox` создаются одной транзакцией. Если интернета нет, карточка показывает «Ожидает отправки» и автоматически отправляется после восстановления связи. Редактирование обновляет тот же стабильный ID, архивирование скрывает материал на сайте без удаления истории.

Изображения JPG, PNG и WEBP размером до 10 МБ копируются в управляемый каталог `media/publications` рядом с базой приложения. Renderer не получает путь к исходному файлу. Перед синхронизацией main process загружает файл в защищённый media endpoint и передаёт в публикации только `mediaRef`. Текущая SQLite-резервная копия сохраняет записи публикаций и аутбокс, но не внешний каталог изображений; до успешной загрузки локальный файл следует сохранять вместе с каталогом данных приложения.

На сайте публикации фильтруются по текущим активным CRM-членствам. После перехода ребёнка в другую группу старые групповые объявления перестают быть доступны. Родитель с несколькими детьми получает объединённую ленту без дублей.

Модель и DTO допускают дальнейшее использование заголовка, изображения и периода действия на клиентском экране, но Sprint 4.4D не включает автоматический показ публикаций на втором мониторе.
