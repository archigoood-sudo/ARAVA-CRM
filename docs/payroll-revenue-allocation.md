# Распределение выручки для зарплаты тренеров

ARAVA CRM использует кассовый метод: в базу для процентной зарплаты входит только фактически полученная выручка за вычетом возвратов. Неоплаченный долг не считается доходом.

Для пакетного абонемента чистая оплаченная сумма делится на лимит занятий. Полученная стоимость одного посещения относится к конкретному занятию через уникальную операцию `LESSON_WRITE_OFF` в журнале абонемента. Для безлимитного абонемента чистая сумма делится на фактическое число использований, но не меньше одного.

Одна запись посещаемости создаёт не более одного активного списания, поэтому одна и та же выручка не попадает в расчёт занятия дважды. Сторнированные списания исключаются. Возвраты уменьшают чистую оплаченную сумму до расчёта распределения; частичные оплаты учитываются только в полученном размере.

Расчётный период можно пересчитать до утверждения. При пересчёте старые начисления периода заменяются новыми. После утверждения период неизменяем и может быть только выплачен.
