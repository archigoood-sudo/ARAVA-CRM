# Приём оплаты через СБП

В окне «Принять оплату» выберите «СБП», укажите ученика и сумму, затем нажмите «Показать QR-код». Клиент сканирует динамический QR-код в банковском приложении. CRM автоматически проверяет статус и создаёт платёж только после подтверждения T‑Bank.

Закрытие окна не отменяет операцию. Незавершённая операция остаётся в истории ученика и может быть проверена повторно. Повторное уведомление банка не создаёт второй платёж.

Реквизиты T‑Bank настраиваются только на сервере ARAVA-WEB. В CRM секреты терминала не хранятся и не отображаются. Возвраты через T‑Bank и онлайн-касса в этой версии не реализованы.
