# Дизайн-система ARAVA

Дизайн-система находится в пакете `@arava/ui` и является общим визуальным слоем всех приложений ARAVA. Доменные правила и тексты остаются за пределами пакета компонентов.

## Принципы

- Иерархия строится крупной типографикой, свободным пространством и контрастом, а не декоративным шумом.
- Карточки имеют радиус 20 px, тонкую границу и почти незаметную тень.
- Основное действие выделяется лаймовым цветом. На одном экране должно быть одно очевидное основное действие.
- Анимации короткие и сдержанные; настройка уменьшения движения в системе всегда соблюдается.
- Компоненты должны одинаково работать в светлой и тёмной темах, с клавиатурой и программами экранного доступа.

## Палитра

| Назначение      | Значение  |
| --------------- | --------- |
| Боковая панель  | `#171717` |
| Акцент          | `#9CFF2E` |
| Фон             | `#F7F8FA` |
| Основной текст  | `#1C1C1E` |
| Вторичный текст | `#6E6E73` |
| Ошибка          | `#FF4D4F` |
| Успех           | `#22C55E` |

Токены доступны через `aravaDesignTokens`. Для интерфейса следует использовать семантические классы Tailwind: `bg-background`, `bg-surface`, `text-foreground`, `text-muted-foreground`, `bg-accent`, `text-error` и `text-success`.

## Компоненты

- `PageHeader` — единый заголовок страницы с описанием и основным действием.
- `Card` — базовая поверхность для смысловой группы.
- `StatCard` — числовой показатель главной страницы.
- `Avatar` — инициалы пользователя, ученика или контакта.
- `Dialog` — модальное окно с управлением клавишей Escape.
- `EmptyState`, `LoadingState`, `ErrorState` — единые состояния данных.
- `SplashScreen` — брендированное состояние запуска приложения.
- `Button`, `Input`, `Select`, `Textarea`, `Checkbox`, `Table`, `Badge` — базовые элементы управления.
- `StatusBadge` — семантические статусы с едиными тонами успеха, предупреждения и ошибки.
- `ParticipantRow` — доступная строка участника с аватаром, метаданными и действиями.
- `WeekCalendar` — семиколоночное представление повторяющегося недельного расписания.
- `Money` и `formatMoney` — единое отображение сумм из целых денежных единиц хранения.
- `BalanceIndicator` — компактное предупреждение об остатке занятий или задолженности.
- `Receipt` — квитанционное представление неизменяемой финансовой операции.
- `LedgerList` — история списаний, возвратов и служебных операций абонемента.

Любой новый общий паттерн сначала добавляется в `@arava/ui`, документируется здесь и только затем используется в приложении.
